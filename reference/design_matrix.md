# Design matrix (intercept, numerics, treatment-coded factors), columns in the order of `x`

Design matrix (intercept, numerics, treatment-coded factors), columns in
the order of `x`

## Usage

``` r
design_matrix(x, features)
```

## Arguments

- x:

  Aligned features.

- features:

  Output of
  [`feature_description()`](https://adimajo.github.io/glmtree/reference/feature_description.md).

## Value

A numeric matrix.
